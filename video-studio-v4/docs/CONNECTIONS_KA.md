# ALEK VIDEO V4 — დარჩენილი კავშირები (შემოსავლიანი ჩართვის წინ)

## ონლაინ სტატუსი

საიტი `https://video.alek.best` საჯაროდ გამოქვეყნებულია, მაგრამ რეალისტური GPU გენერაცია/ფულით კრედიტების ყიდვა განზრახ ჩაკეტილია; არ გაყიდოთ ჯერ კრედიტები. მომხმარებელი უკვე შეძლებს ფოტო-მონტაჟს თავსებადი ბრაუზერიდან.

## 1. Supabase

უკეთესია გამოყოფილი Supabase პროექტი `ALEK Video`, ევროპულ რეგიონში, რადგან სხვა ALEK საიტების მომხმარებლებისა და მონაცემების შერევა არ გვინდა. მის შექმნას შესაძლოა ახალი ორგანიზაცია/ბილინგის დადასტურება დასჭირდეს; არ ვქმნით საფასურის ავტორიზაციის გარეშე.

- გაუშვით `supabase/001_video_studio.sql` Supabase SQL Editor-ში ან შესაბამისი connector migration-ის საშუალებით.
- Vercel > alek-video-engine > Settings > Environment Variables-ში დააყენეთ `SUPABASE_URL`, `SUPABASE_ANON_KEY` (public), `SUPABASE_SERVICE_ROLE_KEY` (secret, server-only).
- Supabase Auth-ში `Site URL` = `https://video.alek.best`, configure email/password, legitimate transactional e-mail, confirm-email flow.
- შექმნილი Storage bucket `alek-video-assets` არის **private**; წვდომა მხოლოდ შესაბამის მომხმარებელს ეკუთვნის.
- Owner ანგარიშით დალოგინების შემდეგ შეამოწმეთ Supabase Auth `user_id` და შეიტანეთ `VIDEO_OWNER_UID`.

## 2. GPU ძრავი

- თქვენს NVIDIA GPU სერვერზე გადატანეთ საქაღალდე `gpu/`. გაეცანით LTX და FASHN ლიცენზიებს, განსაკუთრებით კომერციულ პირობებს, და მხოლოდ თქვენი თანხმობის შემდეგ გაუშვით ინსტალაცია.
- შეასრულეთ `gpu/INSTALL_GPU_UBUNTU.sh` როგორც იმავე პროექტის README მიუთითებს.
- დააყენეთ SSL + HTTPS; `gpu.alek.best` DNS-ის მისამართი უნდა მიუთითებდეს თქვენს GPU სერვერზე.
- ახალ Vercel გარემოს დააყენეთ `VIDEO_GPU_URL=https://gpu.alek.best` და `VIDEO_GPU_KEY=<server generated private key>`. **GPU გასაღები არასდროს შეიტანოთ frontend JS-ში ან საჯარო ფაილში**.
- რეალურად გენერირებული 5/10/15s ვიდეოებით, ავატარით, FASHN try-on-ით, ფრანგული ხმით გადაამოწმეთ ხარისხი/ხმოვანი სინქრონიზაცია და GPU ღირებულება თითო ვიდეოზე.
- მხოლოდ ამის შემდეგ `VIDEO_GPU_TESTED=true`; გენერაციის გაშვებისთვის `VIDEO_LAUNCH_ENABLED=true`.

## 3. Stripe (მხოლოდ ვიდეოს საკუთარი საიტის ბილინგისთვის)

- შეაერთეთ თქვენი Stripe ბიზნეს-ანგარიში (არ არის დაკავშირებული ამჟამად); გაიარეთ KYC/საბანკო ინფორმაცია, და დაამატეთ გადასახადების შესაბამისი იურიდიული გვერდები და რეალური support კონტაქტი.
- გარემოს ცვლადები: `STRIPE_SECRET_KEY` (test და შემდეგ live), `STRIPE_WEBHOOK_SECRET`.
- Stripe webhook URL: `https://video.alek.best/api/stripe`; მოვლენები `checkout.session.completed`, `checkout.session.async_payment_succeeded`.
- Vercel: `VIDEO_BILLING_ENABLED=true` მხოლოდ მას შემდეგ, რაც KYC დასრულდა, ჩატარდა წარმატებული GPU ტესტები და დამოწმდა webhook უსაფრთხოება + ბალანსის დათვლა + refund/რეკონსილაცია.
- კრედიტის პაკეტები და ვიდეოს ღირებულება ჯერ **სატესტო საორიენტაციოა**; გადახედეთ GPU რეალური ღირებულების შემდეგ.
- `CRON_SECRET` საჭიროა დაკარგული/გაჭედილი გენერაციების რეკონსილაციისთვის. დაიგეგმოს პერიოდული მონიტორინგი Vercel Cron ან სხვა scheduler-ით. `POST https://video.alek.best/api?action=reconcile`, Authorization Bearer secret.

- სამომავლო Developer Mode ტესტი: `https://video.alek.best/mcp` (მხოლოდ read-only script-preparation capabilities; **არ ქმნის ვიდეოს ჯერ**).
