FAQ

What is ALK?

ALK is the ERC-20 token of the ALEK project. The current deployment is on Ethereum Sepolia testnet.

Can I see the contract?

Yes. The current contract is publicly verifiable on Blockscout through the “View Verified Contract” buttons on this page.

Why does my balance need a wallet?

The website reads the connected wallet address and calls the token's standard balanceOf function. ERC-20 balances are stored on-chain, while decimals control how the raw integer is displayed.

Is this an investment or guaranteed profit?

No. The project website does not promise returns. The intended model is to build useful products and services first, with transparent token utility.
